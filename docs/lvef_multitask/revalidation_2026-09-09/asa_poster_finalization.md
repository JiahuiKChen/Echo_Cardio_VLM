# A1122 presentation revision

The audience-facing poster is generated by `build_asa_poster.py`. It preserves
the accepted title, six owner-supplied authors and affiliations, the complete
21-measurement panel, separate LVEF analysis, and all four planned paired
comparisons. The original draft builder and its outputs remain historical.

The revision replaces the draft banner and internal aggregate-hash footer with
a research question, three-step workflow, an LVEF dot-and-interval plot, a
plain-language conclusion, concise limitations, and EchoPrime/data references.
Video, recorded measurements, and combined inputs have consistent colors.
LVOT VTI alone is displayed in centimetres by dividing each existing millimetre
MAE by ten. No source label, model, prediction, bootstrap or interval changes.

The successor imports the unchanged `validated_inputs` reader from
`build_asa_draft.py`. It requires independently observed SHA-256 bindings for the
aggregate bundle, paired supplement and private author metadata. The full panel,
all six analysis conditions, source bindings and four-claim Holm family are
validated before rendering; only the primary condition is displayed. The output
receipt records every displayed estimate and denominator, the unit conversion,
and the generated PDF hash. The PDF uses ordinary 95% intervals and separately
labels multiplicity-adjusted p values.

Run with the actual privately held inputs and their observed hashes:

```bash
python docs/lvef_multitask/revalidation_2026-09-09/build_asa_poster.py \
  --bundle /path/outside-git/aggregate_bundle.json \
  --supplement /path/outside-git/asa_supplement.json \
  --authors /path/outside-git/author_details.json \
  --bundle-sha256 OBSERVED_BUNDLE_SHA256 \
  --supplement-sha256 OBSERVED_SUPPLEMENT_SHA256 \
  --authors-sha256 OBSERVED_AUTHOR_SHA256 \
  --output /path/outside-git/asa_a1122_poster_final.pdf \
  --receipt /path/outside-git/asa_a1122_poster_final.receipt.json
```

Validation consists of the maintained aggregate checks, readback of the PDF and
displayed-value receipt, and visual inspection of the actual rendered page.
This presentation change does not call for another scientific run or fixed-test
release. Historical test exposure, report-value reference limitations,
acquisition uncertainty, potential image cues and uncertain clinical importance
remain explicit on the poster.

The final poster and its numerical receipt remain owner-local outside Git.
The current staged export gate has no PDF profile and rejects binary additions;
the source/documentation push does not weaken or bypass that gate. Removing a
draft label does not upload the poster, send a message, or establish conference
submission. The owner-approved presentation revision is ready for local use.

Reference identities used in the footer were checked against the primary
[EchoPrime publication](https://www.nature.com/articles/s41586-025-09850-x) and
[MIMIC-IV-ECHO version 1.0](https://physionet.org/content/mimic-iv-echo/1.0/).
The separate LVOT VTI/TAPSE poster informs the design only; its numerical
results, authors and validation claims are not imported.
